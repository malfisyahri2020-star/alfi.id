Pendahuluan: Kabel LAN / Ethernet

Dalam dunia jaringan komputer modern, komunikasi data antar perangkat sangat bergantung pada media transmisi fisik maupun nirkabel. Salah satu media fisik yang paling esensial dan diandalkan dalam transmisi data berkecepatan tinggi adalah Kabel LAN (Local Area Network) atau yang sering disebut juga sebagai kabel Ethernet.

Kabel LAN berfungsi untuk menghubungkan perangkat jaringan seperti komputer, laptop, switch, router, dan printer dalam area lokal yang terbatas (seperti ruangan, kantor, atau laboratorium). Dengan menggunakan standar kabel UTP (Unshielded Twisted Pair) berbalut konektor RJ-45[cite: 1], transmisi paket data dapat dilakukan secara stabil, aman, dan memiliki latensi yang sangat rendah dibandingkan jaringan nirkabel (Wi-Fi).

Materi & Panduan Praktikum Jaringan

Eksplorasi lengkap mulai dari pengenalan alat, perakitan kabel, konfigurasi IP, hingga transfer file.

01

Alat & Bahan Pembuatan Kabel LAN

Untuk merakit kabel LAN tipe Cross maupun Straight, beberapa alat utama yang disiapkan meliputi:

  • Kabel UTP (Unshielded Twisted Pair): Media transmisi utama penghantar sinyal data.
  • Konektor RJ-45: Kepala penghubung di kedua ujung kabel UTP[cite: 1].
  • Tang Crimping: Alat untuk mengupas kabel dan menjepit konektor RJ-45[cite: 1, 2].
  • LAN Tester: Alat penguji untuk memastikan koneksi lampu indikator menyala dengan benar[cite: 1].
02

Cara Pembuatan Kabel LAN

  1. Kupas pelindung luar kabel UTP menggunakan pisau pada tang crimping[cite: 1].
  2. urai dan luruskan kabel kecil di dalamnya, lalu susun urutan warnanya[cite: 1]. Untuk tipe Cross (menghubungkan sesama perangkat sejenis seperti laptop ke laptop), ujung satu menggunakan standar T568A dan ujung lainnya T568B.
  3. Potong rapi ujung kabel yang sudah lurus agar sejajar[cite: 1].
  4. Masukkan kabel ke dalam konektor RJ-45 secara perlahan hingga mentok ke ujung dalam[cite: 1].
  5. Jepit konektor menggunakan tang crimping dengan kuat[cite: 1].
  6. Uji menggunakan LAN tester; pastikan lampu indikator menyala berurutan[cite: 1].
03

Menghubungkan 2 Laptop & IP Address

Langkah pengaturan IP Address agar kedua laptop bisa saling mengenali:

  1. Colokkan kabel LAN tipe cross ke port LAN di kedua laptop.
  2. Buka Control Panel > Network and Internet > Network and Sharing Center > Change adapter settings[cite: 2].
  3. Klik kanan pada Ethernet, pilih Properties, lalu pilih Internet Protocol Version 4 (TCP/IPv4)[cite: 2].
  4. Set Manual IP Address (Contoh Laptop 1: 192.168.1.1, Subnet Mask: 255.255.255.0 dan Laptop 2: IP 192.168.1.2)[cite: 2].
04

Pengecekan (Ping) & Transfer File

Pengecekan Keterhubungan (Ping):

  • Buka aplikasi CMD (Command Prompt) di laptop[cite: 2].
  • Ketik perintah ping 192.168.1.2 (sesuai IP laptop tujuan) lalu Enter[cite: 2]. Jika muncul balasan Reply from..., berarti koneksi berhasil.

Cara Transfer File Antar Laptop:

  • Pilih folder atau file yang ingin dikirim, klik kanan pilih Properties > Tab Sharing > Klik Share...[cite: 2].
  • Pilih Everyone, klik Add, atur permission menjadi Read/Write, lalu klik Share[cite: 2].
  • Buka File Explorer di laptop kedua, pilih menu Network, cari nama komputer pengirim, dan ambil file yang disharing dengan mudah[cite: 2].
